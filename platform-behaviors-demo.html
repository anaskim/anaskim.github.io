for Custom Elements

Closing the gap between native elements and web components

The problem

Custom elements can't access native behaviors built into HTML elements.

  • No way to trigger implicit form submission ("Enter to submit")
  • No native popover invocation from custom elements
  • No label association or focus delegation
  • No radio button grouping or mutual exclusion

Developers are forced into workarounds that are fragile, incomplete, and inaccessible.

Form submission: today vs. with behaviors

Today — ~50 lines

class MySubmitButton extends HTMLElement { static formAssociated = true; constructor() { super(); this._internals = this.attachInternals(); this.attachShadow({ mode: 'open' }); this.shadowRoot.innerHTML = `<slot></slot>`; // Manual click handling this.addEventListener('click', () => { if (this._internals.form) this._internals.form.requestSubmit(this); }); // Manual keyboard activation this.addEventListener('keydown', (e) => { if (e.key === ' ' || e.key === 'Enter') { e.preventDefault(); this.click(); } }); } // Manual focusability connectedCallback() { if (!this.hasAttribute('tabindex')) this.setAttribute('tabindex', '0'); this._internals.role = 'button'; } }

With Behaviors — 10 lines

class MySubmitButton extends HTMLElement { static formAssociated = true; constructor() { super(); this._submit = new HTMLSubmitButtonBehavior(); this._internals = this.attachInternals({ behaviors: [this._submit] }); this.attachShadow({ mode: 'open' }); this.shadowRoot.innerHTML = `<slot></slot>`; } }

What you lose vs. what you get

❌ Today’s custom elements

  • Can’t do implicit submission
  • Can’t participate in :default
  • No formAction, formMethod, formEnctype, formNoValidate, formTarget
  • Must sprout tabindex for focusability
  • Must manually implement keyboard activation
  • No name/value in FormData as submitter

✅ With behaviors

  • Implicit form submission
  • Keyboard activation (Space/Enter)
  • Implicit role="button"
  • Automatic tab order participation
  • :default pseudo-class matching
  • formAction, formMethod, formEnctype, formNoValidate, formTarget
  • name/value in FormData as submitter

~80% less code, and it does more.

Implicit submission cannot be easily polyfilled today.

API design principles

  • Composable — Multiple behaviors can coexist on one element
  • Explicit — Behaviors are real objects with typed properties
  • Immutable after attachment — No <input type> switching problems
  • Accessible by default — Implicit roles and focusability out of the box
  • Polyfillable — Even easier with developer-defined behaviors…
// Feature detection and graceful fallback if (typeof HTMLSubmitButtonBehavior !== 'undefined') { this._submit = new HTMLSubmitButtonBehavior(); this._internals = this.attachInternals({ behaviors: [this._submit] }); } else { this._internals = this.attachInternals(); this.addEventListener('click', () => this._internals.form?.requestSubmit(this)); }
